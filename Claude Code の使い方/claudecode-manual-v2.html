基本操作

terminal

起動方法

# プロジェクトフォルダで起動
cd your-project
claude

# 最後のセッションを再開
claude --continue

# セッション選択して再開
claude --resume
code

非対話モード（スクリプト用）

# テキスト出力
claude -p "ファイルを要約して"

# JSON出力
claude -p "API一覧をJSON形式で" \
  --output-format json

# ストリーミング
claude -p "ログを分析" \
  --output-format stream-json
security

権限モード

# 自動判定モード
claude --permission-mode auto \
  -p "lintを修正"

# 編集のみ自動許可
claude --permission-mode acceptEdits

CLAUDE.md — 永続的な指示書

info
CLAUDE.mdはセッション開始時に毎回読み込まれる。Claudeへの「お願い書き」。

配置場所と優先度

場所対象範囲Git管理
~/.claude/CLAUDE.md全プロジェクト共通不要
./CLAUDE.mdこのプロジェクト全員あり
./CLAUDE.local.md自分だけ.gitignoreへ
.claude/rules/ファイルパス別ルールあり

書くべき内容 / 書かない内容

check_circle

書くべき内容

  • ビルド・テストコマンド
  • コード規約（インデント・命名規則）
  • アーキテクチャの決定事項
  • よくあるミス・注意点
  • NGな表現・禁止事項
  • 文体・トーンの指示
cancel

書かない内容

  • コードを読めばわかる情報
  • APIドキュメント全文
  • 頻繁に変わる情報
  • 長い説明・チュートリアル
  • 200行以上の冗長な指示

MCPサーバー — 外部ツール連携

外部ツール・サービスをClaudeに直接接続するプロトコル。GitHub・Slack・Canvaなどと連携できる。

追加方法

# HTTP型（APIサービス）
claude mcp add --transport http サーバー名 URL \
  --header "Authorization: Bearer TOKEN"

# stdio型（ローカルツール）
claude mcp add --transport stdio サーバー名 コマンド

主なMCPサーバー

サーバー機能用途
GitHubIssue・PR操作GitHub自動化
Canvaデザイン読み取り・生成デザイン作業
Google Calendar予定確認・追加スケジュール管理
Playwrightブラウザ自動化スクレイピング・テスト
Slackメッセージ送受信Slack連携
NotionDB読み書きNotion同期
Gmailメール操作メール自動化
 
/mcp   # セッション内でMCP状態を確認・再接続

Hooks — 自動化トリガー

特定のイベント発生時に自動でシェルコマンドを実行する仕組み。

warning
「毎回〇〇して」という指示はHooksで設定しないと確実に実行されない。設定は .claude/settings.json に書く。

主要なイベント

イベント実行タイミング用途例
SessionStartセッション開始時環境変数設定・初期化
UserPromptSubmitユーザー入力後入力の前処理
PreToolUseツール実行前事前確認・ログ
PostToolUseツール実行後自動lint・フォーマット
Stopセッション終了時ログ保存・クリーンアップ

設定例：ファイル編集後に自動lint

{
  "hooks": {
    "PostToolUse": [{
      "if": "Edit|Write",
      "hooks": [{
        "type": "command",
        "command": "eslint --fix {{file_path}}",
        "timeout": 10
      }]
    }]
  }
}
