star まずここから — claude.ai vs Claude Code

そもそも何が違う？

同じ「Claude」でも、使う場所と目的がまったく違う。まずこの2つを押さえておけばOK。

language
claude.ai
ブラウザ版 / チャット型

ブラウザで開いてすぐ話しかけるだけ。インストール不要。ライティング・調査・アイデア出しに最適。

インストール不要 チャット感覚 誰でも今日から
terminal
Claude Code
ターミナル版 / CLI型

PCのターミナルで動かすツール。ファイルを直接読み書きしたり、GitHubに保存したり、コードを実行したりできる。

ファイル操作 GitHub連携 自動化
tips_and_updates 一言まとめ：「話すだけでいい」なら claude.ai。「PCのファイルを動かしたい」なら Claude Code。

Coworkは「なるもの」じゃなく
「なっていくもの」

Coworkは別のツールじゃない。Claude Codeを使いながら、必要なものを足していったら自然になる状態のこと。

「Coworkにした」じゃなく、気づいたらそうなってる

3つの拡張とは？

extension
スキル
カスタムコマンド

毎回打っている長い指示を、一言コマンドに登録できる。
/HTML作って の一言で全部動く。

electrical_services
MCP
外部ツール連携

GitHub・Canva・Gmailなど外部サービスをClaudeに直接つなげる。「このCanvaデザインを読んで」が可能になる。

bolt
Hooks
出来事で動く自動処理

「ファイルを保存したら自動でプレビュー更新」など、時間ではなく出来事をトリガーにした自動処理。
時間で動く日報スクリプト（cron）とは別物。

tips_and_updates 正直なところ：スキル・MCP・Hooksを一通り使っていれば、それがもうCowork状態。特別な手続きはない。

あなたはどれから始める？

こんな人に
language claude.ai

「AIって何？」と試したい。文章を書かせたい、アイデアを出してほしい。今日すぐ触れるものがいい。

こんな人に
terminal Claude Code

PCのファイルをAIに触らせたい。HTMLを作りたい、GitHubに保存したい。設定は少し面倒でも構わない。

こんな人に
extension + Cowork

Claude Codeを使い始めて「もっと便利にしたい」と感じた人。焦らなくていい。使いながら自然になる。

tips_and_updates 結論：claude.ai → Claude Code → 気づいたらCowork、の順で育てるのが一番ストレスが少ない。最初からフル装備を目指さなくていい。
